# Python GUI Calculator

My first Python GUI application — a simple calculator with a few fancy extra features.

## About

The goal of this project is to create a simple and easy-to-use calculator with a graphical user interface (GUI).
When finished, the calculator should be able to handle normal calculations such as:

* Addition `+`
* Subtraction `-`
* Multiplication `×`
* Division `÷`

It will also include some more advanced mathematical features, such as:

* Calculations with **π (pi)**
* Powers such as **x²** and **x³**
* Square roots **√**
* Other mathematical functions may be added later

## Goal

The main goal is to build my first Python GUI application while learning how graphical user interfaces work in Python.

The calculator will start as a simple project, but I plan to add more features as I develop it.

## Status

🚧 **In development**

The calculator is not finished yet. More features and improvements will be added over time.
